# 隐私与数据流向说明

本文说明奶昔 · 桌面智能体在运行过程中**哪些数据留在本机、哪些会被发送到你配置的第三方服务、以及怎么关掉**。
撰写依据是代码中真实存在的出站调用（`desktop_core/` 内的 API 主机名），不是抽象承诺。

## 一、留在本机、默认不外发的数据

| 数据 | 位置 | 说明 |
|---|---|---|
| 对话历史、记忆、知识库、工作流、配额记录 | `resources/data/naixi_desktop.db`（SQLite） | 本地数据库；文本字段落库前做加密迁移 |
| API Key 等凭据 | 同上，`api_providers` 字段 | 加密落库，前端只回传掩码；接口返回一律掩码 |
| 配置 | 同上（`desktop_config` / `live_config`） | 结构带 `schema_version`，升级时自动迁移且不删用户键 |
| 日志 | 用户数据目录下的 `logs/` | 仅本机，用于排障 |
| 本地模型（TTS/语音/视觉兜底） | 安装目录 `resources/` 下模型缓存 | 首次使用时按需下载 |
| 摄像头画面（面捕） | 不落盘 | 本地实时推理，仅输出表情/姿态参数 |
| 屏幕截图（游戏 Agent / 安全中心） | 临时内存 | 用于视觉识别；是否外发见下节 |

**本产品不做遥测上报**：不采集设备指纹、不统计使用时长、不发送崩溃报告到自有服务器。

## 二、会离开本机的数据（都由你配置的服务触发）

| 用途 | 目标服务（代码中的真实主机） | 外发内容 | 什么时候发生 | 怎么关 |
|---|---|---|---|---|
| AI 对话 / 工作流 | 阿里云百炼 `dashscope.aliyuncs.com`（默认）；可改为 `api.openai.com` 等你自配的 provider | 你的提问、必要上下文、被引用的文档片段 | 你发起对话或工作流时 | 删除对应 API Key 即可彻底断开；不配 Key 时不会发起调用 |
| 视觉识别（屏幕/游戏看屏、安全中心样本分析） | 智谱 `open.bigmodel.cn`、百炼等视觉模型 | **屏幕截图**（可能包含屏幕上的其它窗口内容） | 你启用游戏 Agent / 视觉分析功能时 | 不使用相关功能，或在工具设置中禁用视觉模型 |
| 语音合成（TTS） | Edge-TTS（微软）/ 百炼语音；本地 kokoro-onnx 兜底 | 要朗读的**文本** | 使用云 TTS 时 | 把 TTS 引擎切到「本地 kokoro-onnx」即不出本机（音质较弱） |
| 搜索 / 资料检索 | 本地内置 SearXNG（默认）；若你改成外部实例则请求外发 | 查询词 | 使用搜索能力时 | 默认即本地；不要把 SearXNG 指向外部实例 |
| 直播 / 弹幕 | `live-open.biliapi.com`、`api-live.bilibili.com`（B 站）等你在「连接」页配置的平台 | 直播间 ID、弹幕消息、你自己的账号凭证 | 你开启直播模块时 | 关闭直播引擎 / 不配置平台凭证 |
| 更新检查 | `api.github.com/repos/Hayliy/naixi-desktop` | 仅 GET 版本信息，不上传任何本地数据 | 启动时或手动检查 | 在设置中清空/改写「更新源」 |
| 知识库导入 | `github.com`（导入开源仓库文档时） | 你指定的仓库路径 | 你主动导入时 | 不使用该导入方式 |
| 图像 / 视频生成 | `apihub.agnes-ai.com`、百炼等 | 你输入的提示词与参考图 | 你使用生成功能时 | 不使用该功能 |
| MCP 外部服务 | 你自行添加的 MCP 服务器 | 由该 MCP 工具的定义决定 | 你调用该工具时 | 移除该 MCP 服务器 |
| 离线语音模型下载 | `alphacephei.com`（vosk） | 仅下载模型文件 | 首次启用离线语音时 | 不启用离线语音 |

**一句话原则**：凡是不需要联网的能力（对话历史、知识库检索、Live2D 桌宠、面捕、抬音、本地 TTS、本地搜索）都不出本机；
凡是要"聪明"的能力，都要经过你配置的云端服务，且**不配置凭证就完全不会调用**。

## 三、你的控制权

- **凭据**：在「设置 → 模型服务」里逐项配置/删除 API Key。删除后对应能力立即停止外发。
- **直播**：在「连接」页配置平台；不配置则不连任何直播平台。
- **TTS 引擎**：可选本地引擎，避免朗读文本外发。
- **更新源**：可清空或替换为自建镜像。
- **一键删除本地数据**：卸载时勾选「同时删除我的个人配置与数据」，或在卸载后手动删除
  `%LOCALAPPDATA%\奶昔\resources\data`（数据库）与 `%LOCALAPPDATA%\奶昔\resources\workspace`（工作区文件）。
  **默认不勾选——卸载会保留这些数据，重新安装后继续使用**（见安装器卸载页说明）。

## 四、卸载与数据保留策略（2026-09-22 起）

| 内容 | 卸载后 |
|---|---|
| 程序本体（`sidecar` / `resources\desktop_core` / `python-embed` / `searxng` / `plugins`） | 删除 |
| 用户数据库（`resources\data`）与工作区（`resources\workspace`） | **保留**（勾选「同时删除我的个人配置与数据」才删除） |
| `%APPDATA%\奶昔`（漫游配置） | **保留**（同上，勾选才删除） |
| 开始菜单 / 桌面快捷方式 | 删除 |

保留数据的目录是 `%LOCALAPPDATA%\奶昔\resources\data`，卸载完成页会显示该路径。

## 五、边界与免责

- 本说明覆盖本产品自身的代码行为；你配置的第三方服务（模型、直播平台、MCP 服务器）对数据的处理适用其各自的隐私政策。
- 屏幕截图类功能（游戏 Agent、样本分析）可能捕获到屏幕上与奶昔无关的内容，使用前请确认屏幕环境。
- 如发现代码中的外发行为与本文不符，请提 Issue —— 以代码为准，本文会同步修正。
